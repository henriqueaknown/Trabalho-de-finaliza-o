# 🌎 EcoDicas
### Calculadora de Pegada Ecológica

**Projeto de Conclusão de Curso – Python | 2026**

## 1. Sobre o projeto
O EcoDicas é uma aplicação desenvolvida em Python que busca conscientizar sobre as mudanças climáticas por meio de uma calculadora simplificada de pegada ecológica. O programa analisa hábitos de consumo e estima quantos planetas seriam necessários caso todos tivessem o mesmo estilo de vida do usuário.

## 2. Objetivos
- Promover a conscientização ambiental.
- Identificar hábitos prejudiciais ao meio ambiente.
- Estimar o impacto ambiental individual.
- Incentivar práticas sustentáveis.

## 3. Funcionalidades
- Questionário sobre alimentação, transporte, moradia e consumo.
- Cálculo estimado da pegada ecológica.
- Apresentação do número de planetas necessários.
- Dicas personalizadas de sustentabilidade.

## 4. Tecnologias utilizadas
- Python 3.
- Listas, dicionários e funções.
- Condicionais e laços de repetição.
- Operações matemáticas.
